Source

Le Discours, nouvelle de Geoffroy Streit (Hylst), extraite de Nouvelles satiriques alsaciennes, écrite entre 2021 et 2023, révisée en 2026.

Adaptation en bande dessinée : Geoffroy Streit (Hylst).

Images

Les 16 cases ont été générées localement sur GPU avec Z-Image Turbo (z-image-turbo-sdcpp), sous licence Apache-2.0. Aucun texte n'est incrusté dans les images : les bulles et les récitatifs sont rendus en HTML.

Voix

La voix test d'Armand Dupont a été générée localement avec Qwen3-TTS VoiceDesign (Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign), sous licence Apache-2.0, avec le seed 4209.

Il s'agit d'une voix de synthèse. Aucune voix réelle n'a été clonée et aucune personne réelle n'est imitée.

Polices

Le lecteur utilise les polices système Georgia et Times New Roman. Aucun fichier de police n'est embarqué ni redistribué.

Lecteur web

Lecteur HTML, CSS et JavaScript statique. Aucun appel réseau après le chargement initial, aucun CDN, aucune ressource externe. La politique de sécurité du contenu autorise uniquement les ressources locales.

Provenance

La provenance et les empreintes des assets sont documentées dans media/manifests/assets.json. Les licences détaillées sont dans media/manifests/licences.md.

Diffusion
